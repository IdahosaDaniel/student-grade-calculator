# Student Grade Calculator

A simple C++ console application that calculates a student's average score across three subjects and assigns a grade based on the average.

## Overview

This project was built to practise fundamental C++ programming concepts, including user input, arithmetic calculations, conditional statements, and input validation.

## Features

- Accepts the student's full name
- Collects scores in Mathematics, Physics, and Computer Studies
- Calculates the average score
- Validates scores to ensure they are between 0 and 100
- Assigns a grade based on the average score
- Displays the student's name, average, and grade
- Formats the average to two decimal places

## Technologies Used

- **Language:** C++
- **Concepts:** Variables, input/output, arithmetic operations, conditional statements, loops, and input validation

## Grading System

| Average Score | Grade |
|---|---|
| 70 and above | Excellent |
| 60–69.99 | Very Good |
| 50–59.99 | Good |
| 45–49.99 | Pass |
| Below 45 | Fail |

## How to Run

1. Clone or download this repository.
2. Open the project folder in a C++ editor or IDE.
3. Open a terminal in the project folder.
4. Compile the source file using a C++ compiler.

If your source file is named `main.cpp`, run:

```bash
g++ main.cpp -o grade_calculator
```

On Windows, run the compiled program using:

```bash
.\grade_calculator.exe
```

Replace `main.cpp` with your actual source filename if necessary.
